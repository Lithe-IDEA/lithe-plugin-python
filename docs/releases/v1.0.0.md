## 中文

- 在 Lithe 0.8.10 及以上版本中，打开首行含 Python shebang 的无后缀脚本即可使用高亮、注释和 Pyrefly 诊断。
- Toolchains 可从 Conda 环境登记表、uv 自定义安装目录和其他受支持的环境位置发现 Python。项目的 `.python-version` 和 `requires-python` 参与解释器选择。
- Pyrefly 与宿主选定的解释器保持一致。插件包内的后端可以在尚未安装 Python 时启动 Pyrefly。
- Build 面板可用 pytest 收集测试，按已发现的套件和用例精确运行。运行 pytest 和 debugpy 仍需要可用的项目解释器。

### 升级与兼容性

Python Support v1.0.0 要求 Lithe 0.8.9 或更新版本。Lithe 0.8.9 支持安装此插件并处理 `.py`、`.pyi` 和 `.pyw` 文件。从 0.8.10 开始，Lithe 还能按 shebang 自动识别无后缀脚本。

使用兼容的旧版 Lithe 时，仍可手动安装 [Python Support v0.1.1 预发布版](https://github.com/Lithe-IDEA/lithe-plugin-python/releases/tag/v0.1.1)。手动安装时请选择对应操作系统和架构的 ZIP。

## English

- With Lithe 0.8.10 or later, open extensionless scripts with a Python shebang to get highlighting, comment commands, and Pyrefly diagnostics.
- Toolchains can find Python from the Conda environment registry, a custom uv installation directory, and other supported environment locations. The project's `.python-version` and `requires-python` help select an interpreter.
- Pyrefly uses the interpreter selected in Lithe. The bundled backend can start Pyrefly before Python is installed.
- The Build panel can collect tests with pytest and run an exact discovered suite or case. Running pytest and debugpy still requires an available project interpreter.

### Upgrade and compatibility

Python Support v1.0.0 requires Lithe 0.8.9 or later. Lithe 0.8.9 can install the plugin and work with `.py`, `.pyi`, and `.pyw` files. Starting with 0.8.10, Lithe can also recognize extensionless scripts by their shebang.

On compatible older versions of Lithe, you can still install the [Python Support v0.1.1 prerelease](https://github.com/Lithe-IDEA/lithe-plugin-python/releases/tag/v0.1.1) manually. For manual installation, choose the ZIP for your operating system and architecture.

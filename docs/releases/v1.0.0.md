## 中文

- Toolchains 可从 Conda 环境登记表、uv 自定义安装目录和其他受支持的环境位置发现 Python。项目的 `.python-version` 和 `requires-python` 参与解释器选择。
- Pyrefly 与宿主选定的解释器保持一致。插件包内的后端可以在尚未安装 Python 时启动 Pyrefly。
- Build 面板可用 pytest 收集测试，按已发现的套件和用例精确运行。运行 pytest 和 debugpy 仍需要可用的项目解释器。

### 升级与兼容性

升级需要支持 `toolchainProviders` 0 和 `buildSystems` 1 的 Lithe 桌面版。确认桌面已支持这两项能力后，再安装对应操作系统和架构的插件 ZIP。使用较早桌面版本时，可继续使用 Python Support v0.1.1。

---

## English

- Toolchains can find Python from the Conda environment registry, a custom uv installation directory, and other supported environment locations. The project's `.python-version` and `requires-python` help select an interpreter.
- Pyrefly uses the interpreter selected in Lithe. The bundled backend can start Pyrefly before Python is installed.
- The Build panel can collect tests with pytest and run an exact discovered suite or case. Running pytest and debugpy still requires an available project interpreter.

### Upgrade and compatibility

This upgrade requires a Lithe desktop version that supports `toolchainProviders` 0 and `buildSystems` 1. Once your desktop version supports both capabilities, install the plugin ZIP for your operating system and architecture. Python Support v0.1.1 remains available for earlier versions of Lithe.

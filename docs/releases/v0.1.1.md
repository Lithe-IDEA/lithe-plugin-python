0.1.1 修复在可写插件目录（如 Windows 默认安装路径）下启动 `debugpy` 调试会话时，`debugpy/adapter` 拉起的 `debugpy/launcher` 子进程未继承 `-B` 而在插件包 `vendor/debugpy/` 内生成 `__pycache__` 字节码的问题：

- 新增隔离启动入口 `scripts/debugpy_adapter.py`（以 `python -I -B` 运行），在加载 `vendor/debugpy/adapter/__main__.py` 前显式设置 `PYTHONDONTWRITEBYTECODE=1`，确保 `debugpy/launcher` 与被调试进程均不会向已安装插件目录写入任何 `.pyc` 字节码文件，同时兼容 Python 3.9–3.14 的 `-I` 隔离模式。

- 按插件契约 v0（`schemaVersion: 0`、`pluginAPIVersion: 0`）构建，需配合新版 Lithe 桌面端（`desktop-v*` 预发布）。

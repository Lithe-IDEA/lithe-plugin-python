Python Support 首个预发布版本（M1 + M2 声明式插件），基于 Pyrefly `1.4.1` 与 debugpy `1.8.22` 为新版 Lithe 桌面端提供开箱即用的 Python 开发支持：

- **Python 语言与静态分析**：识别 `.py` / `.pyi` / `.pyw`，内置 6 平台预打包的 Pyrefly `1.4.1` 语言服务器（`pyrefly lsp`），提供实时类型检查、跳转定义、查找引用、悬停文档、自动导入补全及工作区排除目录同步，原生识别项目 `.venv` 虚拟环境。
- **工具链与虚拟环境解析**：支持项目固定解释器、`.venv` / `venv` 项目内虚拟环境（受宿主工作区信任开关保护）、`VIRTUAL_ENV`、`PATH` 以及 Homebrew、Framework、系统路径、`pyenv` / `pyenv-win`、`uv`、`conda` / `miniforge` / `miniconda` / `anaconda` 自动发现。
- **项目模型、构建任务与测试**：纯静态 AST + `tomllib` / 内置 `tomli` 模型分析脚本（零用户代码执行），自动识别 `[project.scripts]`、包 `__main__.py`、顶层 `__main__` 脚本、Django `manage.py`、FastAPI 与 Flask 运行入口；拆分 `python`（`pip install -r requirements.txt`、`mypy`、`pytest` JUnit XML 报告与用例过滤）、`uv`（`sync` / `lock`）、`conda`（`env update`）与 `ruff`（`check` / `format`）四个独立构建系统。
- **源码级调试与开发向导**：内置 `debugpy` `1.8.22` 调试适配器（支持本地单文件/目标 `launch` 与远程 `attach` 路径映射，自动保持已安装插件目录只读不写入字节码）、终端 Python Traceback 点击跳转源码，以及支持 `None` / `venv` / `uv` 环境初始化的新建 Python 项目向导与完整简体中文翻译。

权限：`debug.attach`、`debug.launch`、`languageServer.launch`、`process.build`、`project.generate`。

兼容性与已知限制：
- 按插件契约 v0（`schemaVersion: 0`、`pluginAPIVersion: 0`）构建，需配合支持声明式契约 v0 的新版 Lithe 桌面端（`desktop-v*` 预发布）；项目内 `.venv` / `venv` 解释器自动探测与信任开关需配合包含 `1lck/Lithe-IDEA#2136`（及 `Lithe-IDEA/Lithe-core-rust#93`）的桌面端版本。
- 本版本为预发布（Pre-release），Lithe Store 自动追踪会跳过它，暂不自动进入正式插件市场索引。

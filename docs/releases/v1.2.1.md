## 中文

- 支持插件增量更新。支持该功能的 Lithe 桌面端在保留了匹配的旧安装包时，可以下载较小的补丁来更新 Python Support。首次安装、旧包缺失或补丁校验失败时，仍可使用完整安装包。

### 升级与兼容性

系统与插件协议要求与 Python Support 1.2.0 一致。调试仍需要 Python 3.10 或更新版本。

---

## English

- Python Support now provides delta updates. Lithe desktop versions that support this feature can download a smaller patch when the matching previous archive is available. The full archive is available for first-time installs, when the previous archive is missing, and when patch verification fails.

### Upgrade and compatibility

System and plugin protocol requirements are the same as in Python Support 1.2.0. Debugging still requires Python 3.10 or later.
